SHEET 02 // COMPLETE COMMAND & UI REFERENCE

Day-to-Day Git & GitHub Playbook

Switch between Terminal CLI and VS Code Source Control UI for every single workflow.

01. Setup & Initialize Once per project

Tell Git who you are, then turn a local folder into a Git repo—or download an existing repo from GitHub.

# 1. One-time identity setup
git config --global user.name "Your Name"
git config --global user.email "you@email.com"

# 2. Start new repo OR clone from GitHub
git init
git clone https://github.com/user/repo.git
  • Open Source Control: Press Ctrl+Shift+G (Mac: Cmd+Shift+G) or click the branch icon in the left Activity Bar.
  • New Repo: Click the blue Initialize Repository button.
  • Clone Repo: Click Clone Repository, paste the GitHub URL, and pick a local folder.

02. The Day-to-Day Save Loop Every 15–30 mins

Inspect your edits, stage the files you want in the snapshot, commit with a clear message, and sync with GitHub.

git status # See modified/untracked files
git diff # Inspect exact line changes
git add . # Stage all changes
git commit -m "feat: add hero banner"
git pull --rebase # Get team updates first
git push # Upload commits to GitHub
  • Inspect Diff: Click any modified file under Changes to open a side-by-side red/green diff view.
  • Stage: Hover over a file (or Changes) and click the + (Stage Changes) icon.
  • Commit & Sync: Type your message in the input box, press Ctrl+Enter (or click Commit), then click Sync Changes.

03. Branching & GitHub PRs Safe experimentation

Never break main. Create an isolated branch for each feature, push it to GitHub, and open a Pull Request.

git switch -c feat/dark-mode # Create & switch
# ...make edits, git add, git commit...
git push -u origin feat/dark-mode
# Open GitHub → Click "Compare & pull request"
git switch main && git pull # After PR merge
  • Create Branch: Click the branch name (e.g. main) in the bottom-left status bar → select + Create new branch...
  • Publish Branch: Commit your work, then click Publish Branch in Source Control.
  • Open PR: Click the GitHub notification popup in VS Code or visit your repo on GitHub to create the Pull Request.

04. Time-Travel & Fixing Mistakes Panic-free coding

Made a typo in a commit message? Broke a file? Need to switch tasks mid-edit? Git has a clean escape hatch for each.

git restore index.html # Discard unstaged edits
git restore --staged . # Unstage files safely
git commit --amend -m "fix: better msg"
git stash # Shelve uncommitted work temporarily
git revert HEAD # Safely undo a pushed commit
  • Discard File Edits: Click the curved back-arrow Discard Changes icon next to a file in Source Control.
  • Unstage: Click the − icon next to a staged file.
  • Amend / Stash: Click the ••• (More Actions) menu at the top of Source Control → Commit → Commit Staged (Amend) or Stash.
